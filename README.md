### 🚀 Featured Project: Arcan

<table>
<tr>
<td width="60%">

**[Arcan — AI Automotive Repair Assistant](https://carschat.cc)**

An AI mechanic that actually knows cars. Not generic ChatGPT answers — real diagnostics with wire colors, pin numbers, torque specs, and step-by-step procedures for specific vehicles.

**What it does:**
- 💬 AI chat with vehicle-specific repair advice (500+ models, 1980–2026)
- 🔌 Interactive wiring diagrams with wire tracing and click-to-diagnose
- 📱 OBD2 Bluetooth scanner with 12 live data gauges
- 📷 Image upload with AI vision analysis (Llama 4 Maverick)
- 💰 Stripe billing with tiered subscriptions
- 🧠 RAG-powered answers from indexed automotive databases

**Tech stack:**
`Next.js 16` `TypeScript` `Python` `FastAPI` `ChromaDB` `Prisma` `SQLite` `Stripe` `AI SDK v6` `Cloudflare Tunnel`

</td>
<td width="40%">

```
Browser → Next.js → 9router (40+ LLMs)
```

**Stats:**

- ⚡ 33 circuit types
